## ✨ Features

- **Intelligent Search** - Find movies with real-time search suggestions
- **Personalized Recommendations** - Discover movies based on your preferences
- **Trending Analytics** - View what's popular based on community searches
- **Detailed Movie Profiles** - Comprehensive information including ratings, cast, and reviews
- **Offline Support** - Recently viewed movies available without internet connection
- **Cross-Platform** - Works seamlessly on both iOS and Android

## 🛠 Tech Stack

- **Frontend**: React Native with TypeScript
- **Styling**: Tailwind CSS via NativeWind
- **Backend**: Appwrite for data persistence
- **State Management**: React Context API
- **API**: The Movie Database (TMDB) API
- **Development**: Expo for rapid iteration

## 💻 Installation

### Prerequisites

- Node.js v16 or later
- npm or yarn
- Expo CLI (optional but recommended)

```bash
# Clone the repository
git clone https://github.com/Prasant46/CineVibe--The-Movie-App.git
cd CineVibe--The-Movie-App

# Install dependencies
npm install

# Install Expo CLI globally (if not already installed)
npm install -g expo-cli
```
